# Architectural Brief

## Purpose
Reconstruct and document a 1970s residential house as a coordinated architectural and BIM project. Preserve original-era character while recording any proposed modernizations separately.

## Deliverables
- Existing-condition floor plans, elevations, and sections (when source evidence is available)
- Revit BIM model with documented units, levels, and assumptions
- Material and component schedules / bill of materials
- Existing / demolition / proposed drawing distinctions, where applicable
- Reference register, design decision log, and model quality checks

## Evidence policy
Do not invent measurements, assemblies, site conditions, or code compliance. Label dimensions and historical features as **verified**, **estimated**, or **unknown**. Verify jurisdiction and applicable codes before treating any proposal as buildable.

## Current status
Initial repository scaffolding. Existing source drawings, exact geometry, and completed Revit deliverables have not yet been verified in this repository.
